# STS Benefits

Gives registered customers an automatic discount (default 10%) on their first order, with a promotional popup and an admin dashboard with analytics. The admin UI is in Hebrew.

## Features
- Automatic cart discount for eligible customers.
- Eligibility modes: **unused benefit** (anyone who has not yet used it) or **new customers** only.
- Exclude specific products or categories.
- Promotional popup that can be switched off.
- Dashboard and settings under **WooCommerce > הטבות**.

## Requirements
WordPress 5.0+, WooCommerce 5.0+, PHP 7.4+.

## Install
Copy the folder to `wp-content/plugins/`, activate, then configure under **WooCommerce > הטבות** settings (percentage, eligibility, exclusions, popup).
